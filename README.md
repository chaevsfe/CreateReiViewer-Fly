# Create Fly: Recipe Viewer

Shows Create Fly's machine recipes in [Roughly Enough Items](https://modrinth.com/mod/rei) and [Just Enough Items](https://www.curseforge.com/minecraft/mc-mods/jei)
on Fabric, Minecraft 26.3, 26.2 and 26.1.x.

## Compatibility

| Component | Version |
| --- | --- |
| Minecraft | `26.3` |
| Mod loader | Fabric Loader `0.20.1` or newer |
| Create Fly | `6.0.9-1` or newer |
| Fabric API | required |
| Java | `25` or newer |
| Environments | Client and server |

## Download

- [Modrinth](https://modrinth.com/project/vMOBLOfr)
- [CurseForge](https://www.curseforge.com/minecraft/mc-mods/create-fly-recipe-viewer)
- [GitHub releases](https://github.com/chaevsfe/CreateReiViewer-Fly/releases)


## Building

```
git clone https://github.com/chaevsfe/CreateReiViewer-Fly
cd CreateReiViewer-Fly
./gradlew build
```

Requires JDK 25.
